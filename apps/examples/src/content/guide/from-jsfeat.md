pixelvision ports jsfeat's algorithms with a simpler, typed API. It isn't a drop-in replacement: the API is new, but the results are the same wherever jsfeat is right. Every ported function is checked against jsfeat 0.0.8 on the same seeded images, and integer output must be identical.

The table and the list of differences below are read from the repository's README and `docs/jsfeat-differences.md` when this site is built, so they always match the code.
