# Differences from jsfeat

pixelvision matches jsfeat 0.0.8 wherever jsfeat is correct; the parity tests in
`packages/parity` require identical integer output there. Where jsfeat gives wrong results, reads
outside the image, silently does nothing or throws, pixelvision fixes it. Every fix is listed here
and covered by a unit test.

Integer rounding is not a bug and is kept: 8-bit and `i32` results are rounded down, as in jsfeat.

## API

pixelvision has its own API rather than jsfeat's:

- Matrices are plain objects `{ type, width, height, channels, data }` with `"u8" | "i32" | "f32" |
"f64"` types instead of bit flags (`U8C1_t`), and no separate `data_t`.
- Functions return their result. Pass `out` to reuse a matrix; there is no global buffer cache
  (jsfeat's 30-buffer pool throws once it runs out).
- Options are named (`gaussianBlur(gray, { kernelSize: 5 })`) instead of positional.
- `ImageData` (or any `{ width, height, data }`) is accepted directly where colour input is expected.
- Most image functions handle any number of channels; jsfeat handled one.

## Fixed behaviour

| Function                                             | jsfeat                                                                                                                                                                                                                                                                                                                                                                                     | pixelvision                                                                                                                                                                                                                                              |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `canny`                                              | Clears the bottom image row before following edges, so edges starting there are lost.                                                                                                                                                                                                                                                                                                      | Finds them. Parity test proves this is the only difference: every extra edge pixel connects to the bottom row.                                                                                                                                           |
| `warpPerspective`                                    | Pixels mapping exactly onto the first row/column (`x = 0`) or the last row/column get the fill value, so even the identity transform loses the border.                                                                                                                                                                                                                                     | Samples the whole image, edges included.                                                                                                                                                                                                                 |
| `warpAffine`                                         | Truncates coordinates toward zero, so points up to one pixel left of or above the image are extrapolated from the edge instead of filled; the last row/column get the fill value.                                                                                                                                                                                                          | Points outside get `fill`; edges are sampled exactly.                                                                                                                                                                                                    |
| `resample`                                           | With more than one channel, rows and pixels are read and written at the wrong offsets. Enlarging silently does nothing.                                                                                                                                                                                                                                                                    | Correct for any channel count. Enlarging (or enlarging one way) uses bilinear interpolation with centre alignment.                                                                                                                                       |
| `boxBlur` / `boxSum`                                 | Reads past the row (or column) when the window is wider than the image. Without scaling, sums are wrapped into 8 bits unless you pass an `i32` output.                                                                                                                                                                                                                                     | Edges repeat for any radius. `boxSum` returns `i32`.                                                                                                                                                                                                     |
| `sobelDerivatives` / `scharrDerivatives`             | Reads row `-1` for images one pixel tall.                                                                                                                                                                                                                                                                                                                                                  | Uses the only row.                                                                                                                                                                                                                                       |
| `integralImage`                                      | Writes into whatever arrays you pass; `Int32Array` squared sums overflow above ~33,000 bright pixels. Column 0 is never cleared.                                                                                                                                                                                                                                                           | Returns `f64` tables, zeroed.                                                                                                                                                                                                                            |
| `gaussianBlur`                                       | The default kernel size can be even (10 for sigma 1), shifting the image by half a pixel; even sizes are accepted.                                                                                                                                                                                                                                                                         | Defaults to `2 * ceil(3 * sigma) + 1`; even sizes throw.                                                                                                                                                                                                 |
| `houghLines`                                         | `hough_transform` assigns undeclared variables in strict mode and throws; its sort comparator returns a boolean; fractional accumulator indices are dropped. It's also missing from the npm build.                                                                                                                                                                                         | Implemented after OpenCV's `HoughLines`, tested on known lines.                                                                                                                                                                                          |
| `perspectiveTransform`                               | Collinear points give a matrix full of `Infinity`/`NaN`.                                                                                                                                                                                                                                                                                                                                   | Throws a `RangeError`.                                                                                                                                                                                                                                   |
| `invert3x3`                                          | A singular matrix gives infinities.                                                                                                                                                                                                                                                                                                                                                        | Throws a `RangeError`.                                                                                                                                                                                                                                   |
| `luSolve`                                            | Returns `0` on failure and overwrites `A` and `b`. Calls any pivot below 1.19e-7 singular, so a well-conditioned matrix of small values fails.                                                                                                                                                                                                                                             | Returns `x`, leaves inputs untouched, throws when singular relative to the matrix's scale.                                                                                                                                                               |
| `choleskySolve`                                      | Only rejects an exact zero on the diagonal; matrices that aren't positive-definite give garbage. Returns `0`/`1`, overwrites inputs.                                                                                                                                                                                                                                                       | Throws when the matrix isn't positive-definite; returns `x`.                                                                                                                                                                                             |
| `svd`, `eigenSymmetric`, `pseudoInverse`, `svdSolve` | Iterate only to single-precision tolerances (1.19e-7) even on double data.                                                                                                                                                                                                                                                                                                                 | Iterate to double precision: results agree with jsfeat to about 1e-7 and are more accurate.                                                                                                                                                              |
| `svd`                                                | Completes U for zero or missing singular values with an LCG in doubles that overflows to `Infinity` after ~60 steps (and can then loop forever); scales rounding residue back up, so U can contain the same vector twice.                                                                                                                                                                  | 32-bit LCG and OpenCV's residue guard: U is always orthonormal.                                                                                                                                                                                          |
| `svdSolve`, `pseudoInverse`                          | Index U with the wrong stride when the matrix isn't square: a consistent 4x2 system solved to `[-0.14, 1.05]` instead of `[2, -1]`.                                                                                                                                                                                                                                                        | Correct least squares for any shape; minimum-norm for underdetermined systems.                                                                                                                                                                           |
| `median`                                             | Returns the lower of the two middle values for even counts, and reorders your array.                                                                                                                                                                                                                                                                                                       | Returns the true median; doesn't modify the input.                                                                                                                                                                                                       |
| `detectFast`                                         | Records each row's candidate corners at `++count` but reads them from index 0: the last corner of every row is dropped and a stale position from three rows earlier is re-checked. Searches one row less than the border allows. Threshold is global state (`set_threshold`); output goes into a preallocated array that throws when too short.                                            | Every candidate is checked; rows up to the border are searched; options per call; returns an array. Parity test: jsfeat's corners are all found, and every extra one is a row's dropped last corner or on the row jsfeat skipped.                        |
| `detectYape06`                                       | Reads 5 rows outside the image for borders under 5. Thresholds are module-level properties.                                                                                                                                                                                                                                                                                                | Border is at least 5; options per call. Otherwise identical.                                                                                                                                                                                             |
| `detectYape`                                         | Its local-maximum test is given half the image width as the row length, so it compares the wrong pixels. It skips the pixel after any weak one, which is exactly the peak of a left-hand corner, so left corners are never found. Scores live in a buffer kept between calls, so earlier frames leak into later ones. Needs `init(width, height, radius)` first.                           | Correct row length; every pixel tested; fresh scores per call; no `init`. The scoring state machine is identical (parity test on the score map).                                                                                                         |
| `describeOrb`                                        | Uses whatever `angle` the keypoint has (`-1` radians by default). Edge samples follow jsfeat's buggy `warp_affine`.                                                                                                                                                                                                                                                                        | Computes the orientation (intensity centroid on OpenCV's rotation-symmetric disc) when `angle` is missing; edges sampled correctly.                                                                                                                      |
| `buildPyramid`                                       | `pyramid_t.build` crashes for a 1-level pyramid (it always writes level 1).                                                                                                                                                                                                                                                                                                                | Any number of levels.                                                                                                                                                                                                                                    |
| `trackPoints`                                        | Takes preallocated pyramids, a flat `[x0, y0, x1, y1, …]` array and a status array to fill.                                                                                                                                                                                                                                                                                                | Takes images (pyramids built for you) or pyramids, and points; returns `{ x, y, tracked }` per point. Results are identical.                                                                                                                             |
| `estimateAffine`                                     | Never rejects collinear samples and ignores `lu_solve` failing, so a degenerate sample still yields a "model" built from stale memory.                                                                                                                                                                                                                                                     | Collinear samples are redrawn; a failed fit is skipped.                                                                                                                                                                                                  |
| `estimateAffine`, `estimateHomography`               | Return the model fitted to the minimal random sample, carrying its noise. Work in single precision (`F32` matrices). Use `Math.random`, so results can't be reproduced. LMEDS overwrites the caller's `params.eps`. Homography divides by `m[8]` unchecked.                                                                                                                                | Refit on all inliers (`refine`, default on); double precision; optional seeded `random`; no side effects; degenerate models rejected. With `refine: false` and the same random numbers, inliers are identical to jsfeat and models agree within 0.01 px. |
| `detectHaar`                                         | The caller builds sum, squared, tilted and Canny integral images. The edge pruning's `mean < 20` test runs before the mean is divided by the area, so it never fires. Grouping averages as `(sum * 2 + n) / (2n)` without OpenCV's integer division, shifting results by up to half a pixel.                                                                                               | Builds the integrals itself; drops the dead test; rounds as OpenCV. Raw detections identical.                                                                                                                                                            |
| `detectBbf`                                          | One pyramid shared by all calls: level 0 is only replaced when the size changes, so a new frame of the same size is searched at the previous frame's full resolution, and offset levels keep stale cells. After a hit in a row's last column, the "skip next window" step pushes the running sample offsets past the row end, and the row padding carries that drift into every later row. | Fresh pyramid per call; offsets computed per row. The parity test runs jsfeat's own BBF source with only the drift removed and gets identical detections.                                                                                                |
| Cascades                                             | jsfeat's cascade files drop the original licence notices. `handopen` has no licence at all.                                                                                                                                                                                                                                                                                                | Notices restored in each file and in `THIRD_PARTY_NOTICES.md`; `handopen` not shipped.                                                                                                                                                                   |
